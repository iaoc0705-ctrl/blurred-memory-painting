# 视觉语法细目

在定调色板、处理笔触、安排构图，或诊断「为什么像照片不像画」时读取。

## 调色板

| 角色 | 色值方向 | 出现位置 |
| --- | --- | --- |
| 底色／天气 | 骨白、石灰白、雾灰、纸白 | 天空、雾、海面反光、大面积留白 |
| 冷调 | 灰蓝、暗青、雾绿、灰紫 | 水面、夜色、阴影面、室内暗部 |
| 暖调 | 赭黄、旧棕、焦糖、尘玫瑰 | 地面、墙面、远山、残留的皮肤色 |
| 叙事暖色 | 琥珀、灯黄、锈橙、晚霞金色 | 灯、窗、一件衣物、落日、暖墙或反光带；面积由情绪决定 |

**颜色的作用**：暖色通常承担时间感、方向或“故事在那边”的暗示。它可以是一处小光点，也可以是一段晚霞、一件外套或一整面旧墙；判断标准是它是否让人产生记忆，而不是面积是否达标。

## 笔触库

| 手法 | 效果 | 用在哪 |
| --- | --- | --- |
| 干笔拖扫 | 边缘变成毛边，形状不封闭 | 人物轮廓、衣摆、头发 |
| 擦涂晕开 | 半透明叠色，空气感 | 天空、水面、雾 |
| 刮除与擦掉重来 | 叠层痕迹，底色透出 | 躯干、暗部、大面积中景 |
| 留白 | 光与空气 | 天空最亮处、水面反光带 |
| 小面积厚涂 | 只有局部有体积 | 地面、墙角、桌角、栏杆 |

不要全画面同一松紧度。人物比背景松、远景比近景松，或一处刻意画实，都是手绘证据。

## 人物处理

- **头是一团形状，不是一颗头骨**：帽檐、头发与下巴的轮廓在逆光里合成一个暗色块，不给出五官分界。
- **手和脚常常只是笔触**：不给手指结构，除非手的动作是这幅画的语义核心。
- **肩线与衣摆负责姿态**：微微前倾是等待，后仰是放松，双臂收拢是自守，重心偏一侧是犹豫。
- **两人之间用间距和朝向讲故事，不用表情**：并肩朝向一致是同路；面对面但视线错开是没说的话；一人正在离开画面是结尾。
- **受光面小于两成**：逆光与剪影是默认，人物绝大多数面积处于暗部或中间调。

## 空场

- 天空、水面或空场通常占较大面积；近景裁切、贴边人物或一件遗留物更有力时，不以比例为限。
- 空场不需要内容，但需要层次：云、雾、水纹、远山、地平线的轻微起伏。
- 地平线略高或略低，避免居中五五开。
- 空场最亮处应靠近画面的视觉引导方向，把观众视线送向人物。

## 室内

- 一个有窗或有一盏灯的暗房间：桌边、吧台、床边、门口、楼梯口。
- 单一暖色光源加大面积暗部，人物常常只剩肩背轮廓。
- 室内比室外更容易画实，要刻意把脸、手和桌面留在暗部，靠窗光勾出边缘。

## 失败诊断

| 症状 | 成因 | 修法 |
| --- | --- | --- |
| 像加了模糊滤镜的照片 | 提示词里只有 blur／soft focus，没有绘画媒介 | 全部换成绘画术语，删掉镜头术语，写明布纹与干笔 |
| 面孔太清楚 | 没指定朝向与遮挡 | 明确背影、转身、帽檐遮脸、头在阴影里，并缩小人物比例 |
| 不够「记忆」 | 场景信息量太大 | 删掉招牌、年代线索、多余道具与第三人，推远人物，扩大空场 |
| 太甜、太伤感 | 暖色过多、光太柔 | 暖色只留一处，其余回到灰蓝与雾灰 |
| 太冷、太疏离 | 全冷色且对比过低 | 加一处暖色光源或暖色地面 |
| 构图太工整 | 视点像摄影师在构图 | 轻微偏心、地平线偏移、让前景挡掉一部分 |
| 太像某张参考图 | 复刻了具体画面 | 换地点类别、人数、朝向、光位、天气，只留调色与笔法 |
| 画面发亮发滑 | 出现清漆反光或高光渐变 | 改为哑光、无清漆，高光只出现在水面与天空 |
| 变成明信片式夕阳 | 景色很漂亮，但人物没有未完成故事，视线只停在太阳与风景 | 只削弱遮蔽故事的部分；可以保留太阳、晚霞或水面暖光，只给人物增加距离、遮挡或未完成动作 |
| 暖色太多但仍有记忆感 | 暖色形成了时间气候或一件物的叙事作用 | 不修。暖色服务于情绪时，它是有效的偏离 |
| 地点或道具不够清楚但情境成立 | 物件像记忆残片，观众能感到“有人留下过” | 不修。清晰度不是目的，情境与余韵优先 |
| 人物像剪贴上去的纸片 | 轮廓闭合、边缘太硬 | 只把边缘拖进背景和地面；保留人物位置、大小、动作和偶然裁切 |
| 第一版有生命，修正后变平 | 把软偏好当硬伤，重新生成改变了构图或情绪钩子 | 丢弃修正版，回到第一版；只修真正硬伤，或不修 |
